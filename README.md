# My Capstone Project

## Overview

This repository contains the setup and development for my capstone project.

## Tech Stack

- Node.js
- Git
- VS Code

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

## Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start the application:

```bash
npm start
```

3. Open your browser and visit:

```
http://localhost:3000
```
